## Default Permission

Play songs natively and show them on the lock screen

#### This default permission set includes the following:

- `allow-set-queue`
- `allow-play`
- `allow-pause`
- `allow-seek`
- `allow-set-volume`
- `allow-set-rate`
- `allow-stop`
- `allow-register-listener`
- `allow-remove-listener`
